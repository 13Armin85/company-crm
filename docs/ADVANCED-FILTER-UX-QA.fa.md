# بهبود فیلتر پیشرفته و انتشار — ۲۰۲۶/۱۱/۱۶

## تغییرات

- ویرایشگر مشترک فیلتر نماها با کارت‌های جداگانه برای فیلد، عملگر و مقدار، راهنمای شروع، تعداد شرط‌ها و کنترل پاک‌کردن همهٔ شرط‌ها بازطراحی شد.
- گروه‌ها انتخاب روشن «همهٔ شرط‌ها / و» و «حداقل یک شرط / یا»، توضیح رفتار و امکان افزودن شرط و زیرگروه دارند. عمق ایجاد زیرگروه محدود نگه داشته شده است.
- فیلد تازه با یکی از عملگرهای مجاز خودش آغاز می‌شود؛ نبود فیلد قابل فیلتر، پیام راهنما و دکمهٔ غیرفعال دارد.
- مقایسه‌های خالی/دارای مقدار، ورودی اضافه نشان نمی‌دهند. مقایسهٔ تاریخ با امروز از تاریخ ثابت قابل تشخیص است.
- پنل فیلتر پیشرفته، پیش‌نویس مستقل دارد: تغییر شرط‌ها تا انتخاب «اعمال فیلتر» درخواست جدید برای نتایج نمی‌فرستد. انصراف، بستن پنل و Escape پیش‌نویس را کنار می‌گذارند. اعمال، صفحهٔ نتایج و انتخاب ردیف‌ها را مانند قبل بازنشانی می‌کند.
- پنل روی نمایشگر بزرگ فضای بیشتری دارد؛ موبایل تک‌ستونه است و دکمه‌های اعمال و انصراف در بخش پایانی چسبان قرار دارند. ویرایشگر مشترک در طراحی جدول‌ها و تنظیمات رسمی نیز ظاهر جدید را دریافت می‌کند.

## آزمون‌ها

- ۱۴ تست در `view-filter.test.tsx`، `view-controls.test.tsx` و `views.test.tsx` موفق بود.
- بررسی TypeScript و ساخت تولیدی وب موفق بود. lint سخت‌گیرانهٔ فایل‌های مرتبط بدون هشدار و خطا اجرا شد.
- `apps/web/tests/browser/crm-advanced-filter.mjs` در محیط توسعه روی صفحهٔ مشتریان، هر ۶ سناریوی ویرایش، انصراف، اعمال، گروه‌های تو‌در‌تو، موبایل ۳۷۵ پیکسلی و پاک‌کردن را تأیید کرد.
- همان آزمون روی سرور اصلی با `CRM_BROWSER_ENTITY=project` و نشست موقت مدیر اجرا شد؛ هر ۷ بررسی موفق بود. بررسی هفتم، قرارداد صفحه‌بندی گزارش روزانهٔ تیم و عدم تکرار افراد بین صفحه‌ها را تأیید کرد. خطای JavaScript ثبت نشد. برای این آزمون، موجودیت‌های واقعی سرور از کاتالوگ خوانده شدند؛ موجودیت آزمایشی `customer` محیط توسعه در سرور وجود ندارد.
- بررسی‌های مرورگر رکورد تجاری یا نمای ذخیره‌شده‌ای ایجاد یا ویرایش نکردند. پیش‌نویس و فیلتر آزمایشی صرفاً وضعیت صفحه بودند؛ نتیجهٔ بدون فیلتر می‌تواند از کش معتبر برنامه بازگردد.
