# معماری فرانت‌اند CRM

کد CRM در `apps/web/app/crm` است و به‌صورت لایه‌ای و ماژولار سازمان‌دهی شده است.
هر لایه فقط به لایه‌های پایین‌تر از خودش وابسته است.

```
pages/ , dashboard/ , engine/     ← صفحه‌ها و ویژگی‌ها (Feature)
        │
components/ , access/             ← کامپوننت‌های مشترک و کنترل دسترسی
        │
api/                              ← لایه داده (React Query + axios)
        │
types.ts , store.ts , utils.ts    ← مدل‌ها، وضعیت سراسری UI و توابع خالص
```

## لایه داده: `api/`

تمام ارتباط با بک‌اند از این پوشه می‌گذرد. ورودی عمومی آن `api/index.ts` است و
بقیه کد فقط از `"./api"` یا `"../api"` import می‌کند؛ فایل‌های داخلی بر اساس دامنه جدا شده‌اند:

| فایل               | مسئولیت                                                                                                                                |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| `client.ts`        | نمونه axios، توکن CSRF، لغو درخواست‌ها هنگام تغییر نشست، `unwrap`، `useSlug`، `workspaceHeaders` و توابع `toastSuccess` / `toastError` |
| `mappers.ts`       | توابع خالص تبدیل پاسخ API به مدل‌های `types.ts` (بدون وابستگی به React)                                                                |
| `user.ts`          | کاربر جاری، پروفایل، آواتار، ظاهر و ترجیحات شخصی                                                                                       |
| `workspace.ts`     | تنظیمات فضای کاری، دعوت‌نامه‌ها و اعضا                                                                                                 |
| `projects.ts`      | پروژه‌ها، وضعیت‌ها، چرخه‌ها، فعالیت‌ها و اعضای پروژه                                                                                   |
| `issues.ts`        | کارهای پروژه و کارهای فضای کاری                                                                                                        |
| `notifications.ts` | اعلان‌ها و شمارنده خوانده‌نشده                                                                                                         |
| `organization.ts`  | مجوزها، نقش‌ها، واحدها و پروفایل سازمانی کاربر                                                                                         |
| `routing.ts`       | قوانین مسیریابی تیکت و صف نقش                                                                                                          |

قواعد:

- هر hook جدید در فایل دامنه خودش قرار می‌گیرد و از `index.ts` به‌صورت خودکار export می‌شود.
- تبدیل داده‌ها فقط در `mappers.ts` انجام شود تا قابل تست واحد باشد.
- پیام‌های موفقیت/خطا با `toastSuccess` و `toastError` نمایش داده شوند، نه مستقیم با store.

## کامپوننت‌های مشترک: `components/`

ورودی عمومی `components/index.ts` است و مسیر import تغییری نکرده است.

| فایل                  | محتوا                                                                                                                                                                |
| --------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `primitives.tsx`      | `Button`، `IconButton`، `PageHeader`، `SectionHeader`، `Avatar`، `StatusBadge`، `PriorityBadge`، `Skeleton`، `EmptyState`، `TabBar`، `SearchBox`، `PersianDateInput` |
| `issue-row.tsx`       | ردیف کار، منوی عملیات کار و `useFilteredIssues`                                                                                                                      |
| `project-card.tsx`    | کارت پروژه                                                                                                                                                           |
| `notifications.tsx`   | کشوی اعلان‌ها و جزئیات اعلان                                                                                                                                         |
| `command-palette.tsx` | پالت فرمان                                                                                                                                                           |
| `create-modal.tsx`    | پنجره ساخت سریع                                                                                                                                                      |
| `toast-region.tsx`    | نمایش پیام‌ها                                                                                                                                                        |
| `breadcrumb.tsx`      | مسیر صفحه                                                                                                                                                            |

## سایر ماژول‌ها

- `access/` — دسترسی مؤثر کاربر، `PermissionGate`، جانشین‌ها و نشست.
- `engine/` — موتور موجودیت‌ها: فرم‌ساز، جدول‌ها، نماها و تنظیمات قوانین.
- `dashboard/` — داشبورد خانه و ویجت‌ها.
- `pages/` — صفحه‌های مسیرها؛ منطق داده را از `api/` و نمایش را از `components/` می‌گیرند.
