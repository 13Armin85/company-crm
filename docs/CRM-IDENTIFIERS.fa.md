# شناسه‌های سیستم

شناسه اصلی رکوردها (`id`) یک UUID است که در سرور تولید می‌شود و از API قابل انتخاب یا تغییر نیست. برای ارتباط میان رکوردها و آدرس API از همین شناسه کامل استفاده کنید.

شناسه پروژه جدید مانند `PRJ000001` خودکار تولید می‌شود. شمارنده مشترک دیتابیس و قفل تراکنش، ساخت هم‌زمان پروژه‌ها را مدیریت می‌کنند. شناسه پروژه‌های جدید میان شرکت‌ها تکرار نمی‌شود و شناسه‌های رزروشده پروژه‌های قبلی، حتی موارد حذف‌شده، کنار گذاشته می‌شوند. پسوند شمارنده از ارقام و حروف لاتین استفاده می‌کند و طول شناسه حداکثر ۱۲ نویسه است.

کار پروژه با ترکیب شناسه پروژه و شماره کار، مانند `PRJ000001-12`، نمایش داده می‌شود. کار خارج از پروژه با `TEAM-12` نمایش داده می‌شود. شماره کار در محدوده پروژه یا شرکت یکتا است؛ برای ارجاع مستقل از شرکت، UUID کامل رکورد را به کار ببرید. شماره کار و شناسه پروژه از API قابل تغییر نیستند. شماره تولیدشده کار خارج از پروژه پس از حذف رکورد دوباره استفاده نمی‌شود.

شناسه‌های قبلی بازنویسی نمی‌شوند و جست‌وجو و ارتباط‌های موجود حفظ می‌شوند. نقش‌ها، کاربران، واحدها، قانون‌های ارجاع، عدم حضور و اعلان‌ها همان UUID کامل خود را برای کپی و جست‌وجو دارند. جست‌وجو ارقام فارسی و عربی را می‌پذیرد و دسترسی به نتایج همچنان تابع مجوزهای کاربر و شرکت جاری است.

کنترل کپی کنار شناسه‌ها قرار دارد. در جست‌وجوی سراسری می‌توان پروژه، کار، کاربر، نقش، واحد یا قانون ارجاع مجاز را با شناسه پیدا کرد. برای موارد دیگر جست‌وجوی صفحه مربوط را استفاده کنید.

پس از دریافت تغییرات، migration `0133_system_identifier_counter` را همراه سایر migrationهای پروژه اجرا کنید. این migration فقط جدول شمارنده را اضافه می‌کند و شناسه یا اطلاعات رکوردهای موجود را تغییر نمی‌دهد.
