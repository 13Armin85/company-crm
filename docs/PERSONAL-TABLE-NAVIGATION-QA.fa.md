# بارگذاری صحیح جدول من

- «جدول من» در جدول‌های صفحات اصلی به مسیر مستقل `/entities/<code>?layout=table` می‌رود.
- صفحهٔ کامل نماها داخل جدول قبلی قرار نمی‌گیرد؛ تنظیم نمای پیش‌فرض هم باعث جایگزینی خودکار و تو‌در‌توی جدول اصلی نمی‌شود.
- در ورود از این مسیر، حالت جدول استفاده می‌شود و ستون‌ها، فیلترها و مرتب‌سازی نمای پیش‌فرض حفظ می‌شوند. این تغییر به‌تنهایی نمای ذخیره‌شده را بازنویسی نمی‌کند.
- تازه‌سازی، نشانی جدول را نگه می‌دارد و بازگشت مرورگر صفحهٔ قبلی را برمی‌گرداند.

## بررسی‌ها

- هفت آزمون واحد `surface.test.tsx` موفق بود؛ مسیر صحیح و عدم جاسازی صفحهٔ نماها با وجود نمای شخصی پیش‌فرض بررسی شد.
- چهار بررسی مرورگر محلی موفق بود: دریافت واقعی داده‌های جدول، تازه‌سازی، عرض موبایل ۳۷۵ پیکسل و بازگشت به فهرست اصلی.
- بررسی TypeScript، lint بدون خطا و هشدار و ساخت وب موفق بودند.
- جزئیات و تصویر مرورگر در `tmp/personal-table-browser` قرار دارد.
- نسخهٔ `release-20261116-personal-table` روی سرور `192.168.10.20` منتشر شد. تطبیق ۱۶۰ فایل وب، سلامت سرویس وب و پاسخ HTTP مسیرها موفق بود؛ سرویس‌های دیگر بدون تغییر ماندند. آزمون مرورگر احرازشده روی سرور اجرا نشد.
