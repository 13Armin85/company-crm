# اصلاح اسکرول افقی و برچسب کاربران

## اسکرول

- کنترل مشترک `TableScroll` کشیدن محتوای جدول را از تعامل با نوار اسکرول مرورگر جدا می‌کند.
- وضعیت کشیدن در پایان تعامل و از دست دادن capture پاک می‌شود؛ کلیک ناشی از کشیدن روی ردیف اجرا نمی‌شود.
- `scrollbar-gutter: stable` در اسکرول مشترک حذف شد؛ در مرورگر Chromium و چیدمان RTL، رزرو این فضا مانع رسیدن کامل به سمت راست می‌شد.
- ثبات نوار اسکرول، خروج موس و رسیدن به انتهای راست در جدول گزارش روزانهٔ تیم و فهرست کارها بررسی شد. کشیدن محتوای گزارش تیم نیز با موس واقعی موفق بود.

## کاربران

- انتخابگرهای کاربران و برچسب مقادیر کاربری در جدول‌ها و خروجی‌ها، نام و نام خانوادگی ثبت‌شده را در اولویت نمایش قرار می‌دهند.
- اگر نام کامل موجود نباشد، نام نمایشی خوانا، نام کاربری خوانا یا ایمیل استفاده می‌شود؛ عدد خالص و UUID به‌عنوان نام نمایشی انتخاب نمی‌شوند.
- جستجوی نام کامل چندبخشی در انتخابگرهای کاربران پشتیبانی می‌شود.
- نام کاربری ذخیره‌شده و اطلاعات ورود حساب‌ها تغییر نمی‌کنند. برای تشخیص موردی که کاربر در خود ستون «نام کاربری» گزارش کرده، تصویر آن قسمت درخواست شده است.

## اعتبارسنجی و انتشار

- ۲۵ آزمون بک‌اند اولیه موفق بود؛ پس از تکمیل تغییرات، ۵ آزمون هدفمند نام کامل، جستجو و fallback نیز موفق شدند.
- بررسی TypeScript، lint، ساخت پکیج UI و ساخت وب موفق بودند.
- نسخهٔ `release-20261117-table-scroll` روی `192.168.10.20` منتشر شد؛ ۱۶۱ فایل وب و سه فایل API تطبیق داده شدند و بررسی تابع نمایش نام روی سرور موفق بود.
- وب، API و پردازشگرهای مربوط با تصویر جدید اجرا شدند؛ سایر سرویس‌ها و محل ذخیره‌سازی سرویس‌ها بدون تغییر ماندند. آزمون مرورگر احرازشدهٔ سرور اجرا نشد.
