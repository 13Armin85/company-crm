# واژه‌نامهٔ فارسی Plane

این واژه‌نامه برای یک‌دست ماندن ترجمه‌های رابط کاربری استفاده می‌شود. نام تجاری Plane، نام سرویس‌ها، شناسه‌ها، URLها و اصطلاحات فنی داخل کد ترجمه نمی‌شوند.

| اصطلاح انگلیسی | معادل فارسی |
| --- | --- |
| Workspace | فضای کاری |
| Project | پروژه |
| Work item / Issue | کار |
| Cycle | چرخه |
| Module | ماژول |
| View | نما |
| State | وضعیت |
| Label | برچسب |
| Estimate | برآورد |
| Member | عضو |
| Assignee | مسئول |
| Priority | اولویت |
| Page | صفحه |
| Inbox | صندوق ورودی |
| Roadmap | نقشهٔ راه |
| Activity | فعالیت |
| Attachment | پیوست |
| Comment | دیدگاه |
| Webhook | وب‌هوک |
| API token | توکن API |

در متن فارسی از نیم‌فاصله، نشانه‌گذاری فارسی و لحن روشن و رسمی استفاده می‌شود. متغیرهای قالب، عبارت‌های ICU و قطعه‌های HTML باید بدون تغییر ساختاری باقی بمانند.
