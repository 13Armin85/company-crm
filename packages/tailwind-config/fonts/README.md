# Vazirmatn

The UI font is self-hosted so it works without a third-party font service.

- Source: https://github.com/rastikerdar/vazirmatn/tree/v33.003
- Original asset: `fonts/webfonts/Vazirmatn[wght].woff2`
- Version: 33.003, variable weights 100–900, Persian/Arabic and Latin glyphs
- License: SIL Open Font License 1.1; see `OFL.txt` in this directory.

The shared stylesheet declares the font and all three app roots preload it.
